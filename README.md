# Elijah Literary Representation

React 19, TypeScript, Vite, Tailwind CSS and GSAP. Sixteen static HTML entry points are generated and prerendered for direct GitHub Pages navigation and readable page content.

## Development

Run `pnpm install`, then `pnpm dev`. Run `pnpm build` for the complete metadata generation, TypeScript check, production build and HTML prerender. Run `node scripts/check-site.mjs` to check built page titles, H1s, local resources, links and anchor targets.

## Content

`src/content.ts` contains the verified biography, editorial copy, original journal essays and a separate illustrative book collection. The three book concepts are explicitly labeled samples, not represented clients. Replace them only with verified project information and permission to display the covers.

Elijah’s original portrait comes from the Lexicon Ink House agents page and remains unaltered. `public/library.webp` is original AI-generated editorial architectural artwork; it does not depict an actual office. Book covers use original CSS artwork. No stock photography is included. CAA is an independent industry reference, not an affiliation claim.

The contact form validates input and prepares an encoded mailto link. It does not send, upload or store inquiries. Delivery requires the visitor to send the draft through their email application.

## Publishing

The active public deployment is GitHub Pages at https://webprod1.github.io/Elijah-Literary-Agent/. Publish the contents of `dist/` to the `gh-pages` branch with `.nojekyll`. Source lives on `main`. All internal paths are relative. Canonicals, Open Graph URLs, robots.txt and sitemap.xml are generated by `scripts/pages.mjs`.

The historical `.openai/hosting.json` records the original private Sites deployment, which is not the active public host.
